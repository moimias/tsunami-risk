# Évaluation des sources
| Critère | Source A (retenue) | Source B (candidate) |
|---|---|---|
| Producteur et URL | USGS — earthquake.usgs.gov/fdsnws/event/1 | NOAA NCEI — ngdc.noaa.gov/hazard/tsu_db.shtml |
| Mode d'accès | API HTTP REST | Téléchargement / API |
| Format | GeoJSON | TSV / JSON |
| Fréquence de mise à jour | Quasi temps réel | Mise à jour périodique |
| Clé ou identifiant | Aucune clé ; `event_id` | Identifiant d'événement |
| Licence / conditions | Domaine public USGS (citer la source) | Données publiques NOAA (citer la source) |
| Risque technique | Limite 20 000 événements par requête | Peu d'événements (quelques milliers) |
| Données personnelles | Aucune | Aucune |
Choix : A répond directement à la question (fréquence des séismes) et le volume est adapté au TP.
